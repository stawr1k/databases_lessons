# Введение в модуль

## Что вас ждёт в модуле

В этом модуле вы изучите ключевые команды для работы с данными в SQL. Вы получите как теоретические знания, так и практические навыки, которые сможете сразу же применить.

Посмотрим, что вас ждёт.

### 1. Создание и изменение таблиц (CREATE и ALTER)

- Узнаете, как создавать таблицы с помощью команды CREATE TABLE.
- Разберётесь, как задавать типы данных для колонок.
- Научитесь добавлять ограничения.
- Поймёте, как изменять уже существующие таблицы с помощью команды ALTER TABLE.

### 2. Добавление данных (INSERT)

- Освоите вставку данных в таблицы с помощью команды INSERT INTO.
- Разберётесь, как вставлять данные только в определённые колонки или сразу во все.
- Научитесь добавлять несколько строк данных за один запрос.
- Узнаете, как обрабатывать возможные ошибки, например нарушения уникальности ключей.

### 3. Изменение данных (UPDATE)

- Научитесь обновлять существующие записи в таблицах с помощью команды UPDATE.
- Разберётесь, как использовать условия, чтобы обновлять только выбранные записи.
- Поймёте, как избежать ошибок при массовом обновлении данных.

### 4. Удаление данных и структур (DELETE, DROP)

- Научитесь удалять записи из таблиц с использованием команды DELETE.
- Разберётесь, как удалять данные выборочно с помощью условий.
- Узнаете, как удалять целые таблицы и базы данных с помощью команды DROP.
- Осознаете риски и последствия удаления данных и структур. Научитесь предпринимать меры для защиты данных.

## Как проходить этот модуль

- После каждого урока есть практическое задание на самопроверку. Обязательно выполняйте его, чтобы закрепить знания. Практика — ключ к успешному освоению SQL.
- Проходите темы последовательно, так как они связаны между собой. Знания из одного урока будут использоваться в другом.
- Не торопитесь. Если что-то не получается, пересмотрите видео, перечитайте материалы или попробуйте выполнить задание ещё раз.

Этот модуль поможет вам уверенно чувствовать себя при работе с таблицами и данными. Удачи!
