# Практика по теме «Команда Update»
### Эта практическая работа поможет вам закрепить знания по теме «Команда Update». Выполнение работы не влияет на прохождение курса, её не нужно отправлять на проверку, но так вы сможете глубже понять материал.



## Как строится работа
- Внимательно прочтите условия задания, перейдите в DBeaver и выполните работу.
- После завершения работы над заданием вернитесь в этот материал и нажмите кнопку «Посмотреть решение». Вам откроется скрипт решения от эксперта.
- Сравните свой вариант решения с предлагаемым. Затем нажмите кнопку «Продолжить», чтобы открылась новая задача.
- Рекомендуем сначала выполнить задания самостоятельно, а уже потом смотреть решение.



## Цели практической работы
- Научиться использовать команду UPDATE для внесения изменений в базу данных.
- Понять, как применять условия (WHERE) для выборочного обновления данных.
- Освоить обновление нескольких столбцов в одной команде.
- Использовать подзапросы для более гибкого обновления записей.
