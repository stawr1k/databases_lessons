# Введение в модуль

**Что вас ждёт**
В этом модуле вы разберётесь с командами обработки данных — одним из ключевых инструментов работы с базами данных. Вы научитесь извлекать, фильтровать и объединять данные — это основа анализа информации и работы с ней в реальных проектах. 

Что вас ждёт:

### 1. Команда SELECT.
- Узнаете, как извлекать данные из таблиц с помощью команды SELECT.
- Поймёте, как фильтровать строки с помощью условия WHERE.
- Разберёте, как сортировать результаты запросов с использованием ORDER BY.
- Рассмотрите, как ограничивать количество возвращаемых строк с помощью команды LIMIT.

### 2. Фильтрация данных.
- Освоите основные принципы фильтрации данных в SQL.
- Научитесь применять операторы AND, OR и NOT для создания гибких условий выборки.
- Разберёте работу с различными типами данных и диапазонами.
- Научитесь извлекать только релевантные данные из больших массивов.

### 3. Объединение запросов.
- Узнаете, как объединять результаты нескольких запросов с помощью UNION и UNION ALL.
- Поймёте, в чём разница между этими командами и как они влияют на результат.
- Разберёте, как использовать INTERSECT для поиска пересечений данных.
- Рассмотрите, как применять команду EXCEPT, чтобы исключать данные одного запроса из другого.
