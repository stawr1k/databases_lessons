# Практика по теме «Фильтрация данных»

Эта практическая работа поможет вам закрепить знания по теме «Фильтрация данных». Выполнение работы не влияет на прохождение курса, её не нужно отправлять на проверку, но так вы сможете глубже понять материал.

## Как строится работа
1. Внимательно прочтите условия задания, перейдите в DBeaver и выполните работу.
2. После завершения работы над заданием вернитесь в этот материал и нажмите кнопку «Посмотреть решение». Вам откроется скрипт решения от эксперта.
3. Сравните свой вариант решения с предлагаемым. Затем нажмите кнопку «Продолжить», чтобы открылась новая задача.

Рекомендуем сначала выполнить задания самостоятельно, а уже потом смотреть решение.

Все задания основаны на данных из базы kinopoisk, SQL-скрипт для создания которой находится под видео «Команда SELECT». 

## Цели практической работы
- Научиться фильтровать данные с помощью оператора WHERE.
- Освоить использование логических операторов AND, OR, NOT.
- Изучить работу с диапазонами значений с использованием BETWEEN.
- Освоить использование оператора LIKE для поиска по шаблонам.
