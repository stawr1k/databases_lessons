# **Практика по теме «Команда SELECT»**


Эта практическая работа поможет вам закрепить знания по теме «Команда SELECT». Выполнение работы не влияет на прохождение курса, её не нужно отправлять на проверку, но так вы сможете глубже понять материал.


## Как строится работа
1. Внимательно прочтите условия задания, перейдите в DBeaver и выполните работу.
2. После завершения работы над заданием вернитесь в этот материал и нажмите кнопку «Посмотреть решение». Вам откроется скрипт решения от эксперта.
3. Сравните свой вариант решения с предлагаемым. Затем нажмите кнопку «Продолжить», чтобы открылась новая задача.

Рекомендуем сначала выполнить задания самостоятельно, а уже потом смотреть в решение.

## Цели практической работы
Научиться: 
- извлекать данные из таблиц с использованием команды SELECT;
- использовать фильтрацию данных по различным условиям с помощью оператора WHERE;
- применять сортировку данных по одному или нескольким столбцам с помощью оператора ORDER BY;
- ограничивать количество возвращаемых строк с помощью LIMIT.

## Подготовка к выполнению практической работы
Все задания основаны на данных из базы kinopoisk, SQL-скрипт для создания которой находится под видео «Команда SELECT». Чтобы подготовиться к выполнению заданий, следуйте инструкциям из видео или воспользуйтесь кратким описанием шагов ниже.
1. Откройте SQL-редактор в DBeaver и выполните следующий SQL-запрос для создания базы данных:
```CREATE DATABASE kinopoisk;```
2. Создайте новое подключение к базе данных: нажмите «Файл» → «Новое подключение», в поле «База данных» укажите kinopoisk. Проверьте соединение, нажав «Тест соединения».
3. Закройте вкладку SQL-редактора, если она привязана к базе данных postgres.
4. В левой панели DBeaver найдите базу данных kinopoisk. Кликните правой кнопкой по kinopoisk → выберите «Редактор SQL» → «Новый редактор SQL». В заголовке вкладки должно появиться название базы данных kinopoisk.
5. Скачайте SQL-скрипт для создания структуры базы данных kinopoisk (файл приложен под видео «Команда SELECT»).
6. Откройте скачанный файл в текстовом редакторе, например в «Блокноте». Скопируйте весь текст скрипта.
7. Переключитесь в SQL-редактор DBeaver и вставьте скопированный скрипт.
8. Выделите весь текст скрипта и нажмите кнопку «Выполнить запрос».
9. В левой панели разверните kinopoisk → «Таблицы», обновите список таблиц. Должно появиться 11 таблиц.
10. Откройте новую вкладку SQL-редактора.

Теперь вы готовы к выполнению запросов!

# Задание 3 «Фильтрация пользователей по дате регистрации»
Выведите пользователей, которые зарегистрировались после 1 января 2023 года. Отобразите их username, email и registration_date.

## Решение к заданию 3
Скрипт решения:
- ```SELECT username, email, registration_date```
- ```FROM Users```
- ```WHERE registration_date > '2023-01-01';```

# Задание 4 «Сортировка пользователей по дате регистрации»

# Задание 8 «Комплексное использование SELECT, WHERE, ORDER BY и LIMIT»
Выведите список пользователей, которые зарегистрировались после 2021 года. Отсортируйте их по дате регистрации и выберите первых 10 пользователей. Запрос должен включать username, email и registration_date.

## Решение к заданию 8
Скрипт решения:

- ```SELECT username, email, registration_date``` 
- ```FROM Users``` 
- ```WHERE registration_date >= '2022-01-01'``` 
- ```ORDER BY registration_date ASC``` 
- ```LIMIT 10;```

# Задание 9 «Показ актёров и их национальностей»
Выведите актёров, чья национальность указана как США. Выведите их имя (actor_name) и дату рождения (birthdate). Отсортируйте по дате рождения (самые старшие актёры вверху).

## Решение к заданию 9
Скрипт решения:

- ```SELECT actor_name, birthdate``` 
- ```FROM Actors``` 
- ```WHERE nationality = 'США'``` 
- ```ORDER BY birthdate ASC;```
