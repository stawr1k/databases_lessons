# Итоги и рекомендации
Поздравляем! Вы дошли до финального модуля курса по SQL. За это время вы освоили множество ключевых концепций и инструментов, которые помогут вам эффективно работать с базами данных. Кратко подведём итоги того, что вы изучили в этом модуле.


#### 1. Команда JOIN:

Освоили разные типы объединений: INNER JOIN, LEFT JOIN, RIGHT JOIN, CROSS JOIN.<br>
Научились правильно выбирать тип JOIN в зависимости от задачи.<br>
Комбинировали разные соединения для более сложных выборок.<br>

#### 2. Группировки и агрегатные функции:

Использовали GROUP BY для группировки данных.<br>
Применяли агрегатные функции (SUM, MAX, MIN, AVG, COUNT) для анализа данных.<br>
Освоили разницу между WHERE и HAVING.<br>

#### 3. Подзапросы:

Научились использовать подзапросы в разных частях SQL-запросов.<br>
Разобрались, когда лучше применять JOIN, а когда — подзапросы.<br>

#### 4. Транзакции:

Поняли, как управлять транзакциями (COMMIT, ROLLBACK).<br>
Изучили уровни изоляции транзакций и их влияние на видимость данных. <br>

#### 5. Индексы и внешние ключи:

Осознали важность индексов для оптимизации поиска данных.<br>
Научились создавать и удалять индексы.<br>
Разобрались с внешними ключами и их влиянием на целостность данных.<br>

#### 6. План выполнения запроса (EXPLAIN):

Научились анализировать выполнение запросов с помощью EXPLAIN.<br>
Поняли, как индексы ускоряют выполнение SQL-запросов.<br>
Что делать дальше<br>
Курс дал вам фундаментальные знания SQL, но работа с базами данных — это постоянное развитие. Вот некоторые рекомендации, которые помогут вам двигаться дальше.<br><br><br><br><br>

#### 1. Книги, которые подойдут как начинающим, так и более опытным пользователям:

-  «SQL для чайников», Аллен Тейлор (Allen G. Taylor).<br>
-  «Освой самостоятельно SQL за 10 минут», Бен Форта (Ben Forta).<br>
-  «Освой самостоятельно SQL за 24 часа», Райан К. Стефенс, Рональд Плю (Ryan K. Stephens, Ronald R. Plew).<br>
-  «Изучаем SQL», Алан Бьюли (Alan Beaulieu).<br>
-  «Practical SQL: A Beginner’s Guide to Storytelling with Data», Anthony DeBarros.<br>
#### 2. Онлайн-ресурсы с практическими заданиями по SQL, которые помогут закрепить полученные знания и улучшить навыки работы с SQL:

- SQL-EX — сайт с большим набором задач для тренировки, включая разбор решений.<br>
- PGExercises — упражнения для работы с PostgreSQL.<br>
- SQLZoo — пошаговые уроки и задачи с проверкой решений.<br>
- HackerRank — раздел SQL на платформе с задачами для тренировки навыков.<br>
- W3Schools SQL Tutorial — учебные материалы с интерактивными упражнениями.<br>
  #### 3. Официальная документация, которая необходима, чтобы освоить SQL на профессиональном уровне и понять все возможности систем управления базами:
- PostgreSQL Documentation — полное руководство по работе с PostgreSQL.<br>
- Документация PostgreSQL — перевод официальной документации на русский язык.<br>
- Углубляйтесь в теорию и практику, экспериментируйте с запросами и находите новые подходы к решению задач!<br>
