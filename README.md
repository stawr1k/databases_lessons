* **[Урок 7 / app.py](./MySQL/Lesson%207/app.py):** Полноценное сервисное приложение интернет-магазина: пул соединений (`MySQLConnectionPool`), автомиграция схемы с 5 связанными таблицами, транзакционное оформление заказа с блокировкой строк (`FOR UPDATE`) и финансовые отчеты (`GROUP BY`, `HAVING`).

## 🚀 Быстрый старт с Docker

Для быстрого локального запуска MySQL 8.4 без установки сервера в систему:

```bash
docker run --name mysql-server -p 3306:3306 -e MYSQL_ROOT_PASSWORD=rootpassword -d mysql:8.4
```

Подключение через консольный клиент:

```bash
docker exec -it mysql-server mysql -u root -p
```
