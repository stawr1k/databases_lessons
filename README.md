# Практические курсы по базам данных

Методические руководства и практические уроки по современным системам управления базами данных (СУБД). Каждый курс содержит минимум 7 структурированных лекций — от фундаментальной теории реляционных моделей и синтаксиса SQL до оптимизации запросов, индексов, транзакций и создания законченных сервисных приложений на языке Python.

## 🚀 Быстрый старт через Docker

### Запуск Oracle Database 23ai Free:
```bash
docker run --name oracle23ai -p 1521:1521 -e ORACLE_PASSWORD=MyStrongPassword123! -d container-registry.oracle.com/database/free:latest
```

### Запуск MySQL 8.4 LTS:
```bash
docker run --name mysql-server -p 3306:3306 -e MYSQL_ROOT_PASSWORD=rootpassword -d mysql:8.4
```
